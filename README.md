## 🚀 How to Run Locally

To view this portfolio on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Goodnews-code/goodnews-code.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd goodnews-code
   ```
3. **Open the project:**
   Simply double-click the `index.html` file to open it in your default web browser, or use an extension like **Live Server** in VS Code.
